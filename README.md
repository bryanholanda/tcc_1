# Accessible Audiobooks — Academic Research

**Historical academic work · Software Engineering · University of Brasília**

LaTeX sources for the academic work **“Audiobooks com navegação por marcações de conteúdo como ferramenta de apoio didático para não-videntes”**, by **Bryan de Holanda Fernandes**. The original research is written in Portuguese.

The work explores audiobook navigation through content markers as a learning aid for people with visual impairments. The related software implementation is preserved in [`player_rab-ogg`](https://github.com/bryanholanda/player_rab-ogg).

## Research and implementation

| Resource | Contents |
| --- | --- |

The repositories are two parts of the same academic effort, not two unrelated projects. This documentation refresh does not change the research or designate the preserved sources as a newly verified final edition.

The document uses the FGA-UnB thesis template developed and adapted by **Professor Edson Alves**. The template's original README, attribution, and Creative Commons Attribution 3.0 reference are preserved unchanged in [`docs/template-readme-original.md`](docs/template-readme-original.md).
